# Youkeo logo assets

- `youkeo-white-transparent.svg` — dark headers, video overlays, and dark photography.
- `youkeo-white-on-black.svg` — presentations and placements that require a supplied dark background.
- `youkeo-black-transparent.svg` — light headers and light layouts.
- `youkeo-black-on-white.svg` — transparent black wordmark for white and light backgrounds.
All wordmark lettering is either white or black. Colour is reserved for the final dot, which replaces the former magenta with the darker violet `#8279BF` from the rebrand palette.

Keep clear space around the wordmark equal to at least the height of the final dot. Use the transparent variants in responsive website headers so the surrounding UI controls the background.
